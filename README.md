Entry for the make.fun competition **The Internet in One Word**.

## The word

**unsubscribe**

One word for the whole internet: a newsletter you never signed up for, and can never leave.

The word is 11 characters, a single word, inside the competition's 1–30 character gate.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
